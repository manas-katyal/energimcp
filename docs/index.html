Åben af design

Read-only, og bygget til modellen.

Der er intet privat bag denne server — den læser et offentligt API. Det den tilføjer, er den dømmekraft en assistent har brug for at bruge API'et ordentligt.

Read-only

Alle værktøjer læser. API'et bagved har slet ingen skrive-endpoints.

Skemaer, ikke gætteri

describe_dataset udleverer hver kolonne med type og enhed, og det første og sidste tidsstempel der rent faktisk findes.

Rate limits respekteres

Svar caches i ét opdateringsinterval, så gentagne spørgsmål er gratis, og en grænse meldes som noget man venter ud — ikke prøver igen.

Sammenfatninger, ikke rådump

Et år med femminutters-data er 105.000 rækker. Bed om en sammenfatning og få min, max, gennemsnit og sum pr. kolonne i stedet.

Bulk holdes ude af chatten

download_url bygger et CSV- eller Excel-link til udtræk der er for store at læse højt. Intet hentes for at bygge det.

Spot er ikke din regning

Priserne er uden tariffer, afgifter og moms, som cirka fordobler en husstandspris — og serveren siger det frem for at lade det passere.

Opsætning

Tre måder at bruge den på.

Den hurtigste vej er vores hostede server: sæt den ind i Claude én gang, så virker den på web, desktop og din telefon.

Tilføj den til Claude

  1. Åbn Indstillinger → Connectors i Claude og vælg Tilføj custom connector.
  2. Kald den EnergiMCP og indsæt URL’en herunder. Ingen login, ingen nøgle.
  3. Færdig. Den dukker op i Claude-appen på din telefon af sig selv.
https://energimcp-production.up.railway.app/mcp
Åbn Connectors i Claude

På telefonen: tilføj den én gang på claude.ai eller i desktop-appen, så følger den med til iOS og Android. Serveren er gratis og kører på åbne data.

Lokalt, over stdio

Med Node 24 eller nyere tilføjer du dette til claude_desktop_config.json eller et projekts .mcp.json. Intet andet at konfigurere.

{
  "mcpServers": {
    "energi": { "command": "npx", "args": ["-y", "energimcp"] }
  }
}

Hostet, over HTTP

Vil du hellere køre din egen? Den samme container kører hvor som helst. Tilføj dit eget endpoint som en custom connector i claude.ai — der er ingen authentication, for der er ingen hemmeligheder.

Deploy på Railway

Ét klik opretter container og en offentlig URL i din egen Railway-konto. Intet betales til os, og der er intet at konfigurere bagefter — ingen nøgler, ingen volumes.

Kom i gang Se koden

EnergiMCP er et uafhængigt open source-projekt og er ikke tilknyttet Energinet, Energi Data Service eller Anthropic. Data udgives af Energinet på deres egne vilkår; læs dem før du bruger dem kommercielt. Day-ahead spotpriser er uden tariffer, afgifter og moms.

Ansvarsfraskrivelse. Brug på eget ansvar. Softwaren leveres som den er, uden nogen form for garanti, og forfatterne påtager sig intet ansvar for hvordan den bruges eller for beslutninger truffet på baggrund af de data den returnerer.
